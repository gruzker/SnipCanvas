# Security

Use the latest release. Screenshots and edits are processed locally. Sharing
opens an app or website at your request; you select the recipient and send.
Captures are saved to your configured folder and shared copies remain in the
system temporary directory until you or the OS removes them.

Blur is a visual effect, not secure redaction. Remove sensitive pixels or crop
them out before publishing an image. Do not include private screenshots or
credentials in public issues, test fixtures, or logs.

Report suspected vulnerabilities through the repository's **Security >
Advisories > Report a vulnerability** option when private reporting is enabled.
If that option is unavailable, open an issue requesting a private contact channel
without disclosing the vulnerability. Include affected versions, reproduction
steps, and impact only through the private channel. Ordinary bugs belong in Issues.

Maintainers: enable private vulnerability reporting before making the repository
public. Keep bundled runtimes patched and refresh their license notices when
updating them. Windows builds are currently unsigned.
